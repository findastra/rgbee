# RGBee plan

*Written 2026-10-09 with Claude Opus 5.5 (`claude-opus-5-5`). Check every API and port below against the vendor's current documentation before building on it; they change.*

## Goal

One place to set the lights Astra has: room lights, mouse pad, mouse, PC and keyboard (and anything else that glows). Pick a scene once and every light follows.

## Why a helper is needed

A web page cannot open raw network or USB connections, so it cannot talk to most lights directly. RGBee v1 adds a small **helper** that runs on Astra's PC, listens only on `localhost`, and does the talking. The web app sends it a scene; the helper sends each light its colour. This is the same house pattern as the Farmer's desktop pet (a small Windows program built with the .NET Framework compiler that ships with Windows), or Node if that is simpler.

## How each kind of light is usually reached

Which route applies depends on the **brand and model** of each light, so RGBee asks for those first.

| Lights | Likely route | Notes |
|---|---|---|
| PC, keyboard, mouse, mouse pad | **OpenRGB**, the open-source app that controls many brands from one place. It can run a local SDK server that a helper talks to. | Brand apps (Razer Synapse, Logitech G HUB, Corsair iCUE, SteelSeries GG, ASUS Armoury Crate and others) often fight OpenRGB for the same device. Pick one owner per device. Some brand apps have their own local SDKs instead. |
| Room lights | Depends entirely on the brand: Philips Hue (a local bridge API), Nanoleaf, LIFX and WLED have local APIs; Govee has a LAN API on some models and a cloud API with a key. | Cloud APIs need a key. Keys live in the helper's local settings on the PC, never in this repo. API Fairy can keep notes about them. |
| Anything else | Listed in the app; given a route when its brand is known. | |

## Moods once it is connected

The Cage's nine meanings, applied to lights:

| Mood | RGBee is saying |
|---|---|
| `sleep` | No lights listed yet, or the helper has not run. |
| `idle` | A scene is on. Nothing to report. |
| `curious` | Talking to the lights. |
| `happy` | Every light took the scene. |
| `worried` | Some lights did not answer. |
| `alarmed` | Most lights did not answer. |
| `sick` | It needs Astra: OpenRGB is not running, a bridge wants its button pressed, a key is missing or expired. It says which in a bubble. |
| `sad` | The helper crashed. |

## Steps

1. **v0 (done, 2026-10-09):** the web app. Lights, scenes, preview desk, backups. No device control.
2. **v1:** the helper, plus OpenRGB for the PC, keyboard, mouse and mouse pad. Card [001](../handoffs/001-any-light-control.md).
3. **v2:** room lights, by brand.
4. **v3:** RGBee's desktop pet with quick chat ("movie night", "lights out").

## Safety

- Effects never flash faster than three times a second, and stop under reduced motion.
- The helper listens on `localhost` only and never sends anything off the PC except to a light's own cloud API when Astra has set one up.
